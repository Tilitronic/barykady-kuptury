Needs a `@resource-manager` refresh — and any model recommendation must be validated against `opencode models` first (its own rule: *"never recommend a model the user doesn't have access to"*).
3. **Background subagents are non-functional in this runtime.** `OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS=true` is exported and visible in the shell env, yet a `background: true` dispatch **froze** (`cod-1`: `state: busy`, frozen `last_activity_at`, no visible agent, then errored on cancel). **Run all lanes foreground/serialized.**
4. **`pkill -f <pattern>` is dangerous here** — a bash command whose own command line contains the pattern kills the shell (two 120–180 s hangs traced to `pkill -f serve-spa.mjs`). Use **pid files** (`echo $! > /tmp/.../x.pid`, `kill "$(cat ...)"`).
5. **Backgrounded servers hold the shell** — start with `(cmd &)` + a pid file and kill **by pid**. Stale `quasar dev` servers accumulate on ports 9000+; a second one lands on 9001/9002. Identify yours by pid before killing anything.
6. **`pnpm test:e2e` self-builds** (`pnpm build` + `serve-spa`), so it writes `dist/` — do not run two build-dependent lanes concurrently in one tree.
7. **Favicon caching** — browsers cache favicons per (origin, URL) and often ignore a reload. Icons carry `?v=N`; **bump N** when regenerating so a change actually reaches the browser.
8. **T-034 remainder:** the web manifest and OG/social-preview images are **not** done (favicon only). Regenerate icons with `node scripts/generate-favicons.mjs`.
9. **T-011 interim placeholders (non-blocking):** hamburger `☰`/`✕` and `SocialLinks` FB/IG text badges — pending an icon-system ticket. `SocialLinks` renders nothing today (D-05 open).
