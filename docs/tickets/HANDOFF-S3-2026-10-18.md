## 5. Known gaps, risks, follow-ups

1. **Background subagents are non-functional in this runtime.** `OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS=true` is exported and appears in the shell env, but a `background: true` dispatch **froze** (`cod-1`: `state: busy`, `last_activity_at` frozen, no visible agent, then errored on cancel). **All lanes must run foreground/serialized.** The session-3 board lists `cod-1` as `error` — do not reuse it.
2. **`pkill -f <pattern>` is dangerous here.** A bash command whose own command line contains the pattern kills the shell (two 120–180 s hangs traced to `pkill -f serve-spa.mjs`). Use **pid files** (`echo $! > /tmp/.../x.pid`, `kill "$(cat ...)"`) — never `pkill -f`.
3. **Backgrounded servers hold the shell.** Start with `(cmd &)` + a pid file and kill by pid; the E2E harness self-manages its own server on `127.0.0.1:4173`.
4. **`pnpm test:e2e` self-builds** (`pnpm build` + `serve-spa`), so it writes `dist/` — do not run two build-dependent lanes concurrently in one tree.
5. **T-011 interim placeholders (non-blocking):** the hamburger uses `☰`/`✕` text and `SocialLinks` uses FB/IG text badges — pending an icon-system ticket. `SocialLinks` renders nothing today (D-05 open), so the badges are not user-visible.
6. **`logotype_black.svg` has no `fill`** (renders `#000000`, not NERO `#262424`); its `_web` derivative inherits this. Kept verbatim for provenance — **needs a re-export from the asset author**.
